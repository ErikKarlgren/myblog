About

I'm an embedded Linux software developer. Most of my work happens close to the hardware: boot, kernel interfaces, device drivers, and the C, C++ and Rust code that sits on both sides of that boundary.

I like problems that only make sense once you know what the machine is actually doing — scheduling, memory, concurrency, and the gap between what a language promises and what the silicon delivers.

What I work on

  • Embedded Linux systems: board bring-up, bootloaders, and the long tail of hardware quirks
  • Kernel and userspace interfaces: drivers, device trees, syscalls, IPC
  • Systems programming in C, C++ and Rust
  • Debugging the kind of bug that never reproduces on a desk
